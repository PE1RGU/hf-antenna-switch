Shack Relay Matrix

A 4-slot × 6-line radio-by-antenna crossbar. Every card plugs into one I2C control backplane; RF stays on a separate matrix. Adding a radio or an antenna is one more card, no controller change. The picture shows today's example state: FT-710 transmitting on the doublet and receiving on the vertical, Airspy listening on the Loop-on-Ground.

Modules

CardWhat is on it
ControllerMCU (I2C master), USB-C with UART/CDC and a plain ASCII command set, hardware watchdog driving /RLY_EN, optional OLED + encoder front panel, header for a later Ethernet/Wi-Fi add-on. Holds the routing table and the interlock rules.
Power13.8 V station supply in, fuse, 12 V relay rail, 5 V and 3V3 for logic. Separate returns for relay and logic current, joined at one point.
Radio PortOne SO-239 for the radio, then a PTT-driven SPDT changeover relay that steers the radio to a TX path (keyed) or an RX path (unkeyed). Each path has six SPST RF relays, one per antenna line; firmware allows at most one closed per path. Same antenna on both paths gives ordinary single-antenna operation. Opto-isolated PTT input drives that slot's PTT[n] line on the backplane. RF sense (diode detector) confirms TX is actually present. I2C expander addressed by the slot's hardwired SLOT_ID, relay drivers gated by /RLY_EN.
Radio Port, RX variantSame card without the PTT input. Adds a TX-mute relay that shorts the receiver port whenever any PTT[n] is active. That is hardwired from the PTT bus, not via firmware, so a hung MCU cannot leave the Airspy exposed.
Antenna PortOne SO-239, gas-discharge surge arrestor, relay that grounds the antenna when no radio is routed to it. An antenna flagged RX-only (the LoG) is refused to any TX-capable radio in firmware.
BackplanePassive PCB. Control signals only, no RF. Slot position sets SLOT_ID, so cards need no jumpers and any card fits any slot of its type.

Backplane signals

SignalPurpose
+12V RLYRelay coil rail, fused per card.
+5V / +3V3Logic supply.
SDA / SCLI2C, controller is the only master. Up to 8 expanders per bus; more via a mux if a second chassis is ever daisy-chained.
/INTWired-OR interrupt from expanders (PTT edge, fault).
PTT[1..4]One line per radio slot, driven by that slot's Radio Port card, readable by every card. Carries the hardware RX protection.
/RLY_ENGlobal relay enable from the controller watchdog. Released, every antenna-select relay opens and every antenna port falls to ground: the safe state.
SLOT_ID[2:0]Hardwired per slot, read by the card to set its I2C address.

Rules the controller enforces

  1. One radio per antenna line, one antenna per radio. Two TX radios can never share a line.
  2. No antenna-select relay moves while that radio's PTT is active (hot-switch lockout). RX-mute relays are exempt because they are driven straight from the PTT bus.
  3. Break before make, with a settle delay between opening the old path and closing the new one.
  4. RX-only antennas may sit on a radio's RX path, never on its TX path.
  5. The changeover relay is driven from the PTT bus in hardware. The radio's TX delay (FT-710 menu, external-amp keying delay) must exceed the relay transfer time so RF never hits a moving contact.
  6. Loss of watchdog kick, USB command timeout or brown-out drops /RLY_EN.

Expansion path

Second transceiver: fit a Radio Port card in slot 3, run its PTT to the card, add one line to the routing table. Vertical antenna: fit Antenna Port 3, which is already wired to line A3. Beyond 4 × 6, either a second chassis on the same USB host with its own controller, or a controller firmware option to drive a second backplane through an I2C mux. Remote relay boxes at the mast base would replace the I2C link with RS-485 on the same card footprint; the backplane signal set is chosen so that swap is a transceiver change, not a redesign.
