**Finding F1 (firmware).** After reset the output register is 1. If the firmware sets a pin to output (configuration 0) before it writes 0 to the output register, that coil switches on at once (row 'running, config 0, output 1'). Rule: write the output registers (2, 3) to 0x00 first, then the configuration registers (6, 7).

## 5. K0 (TX/RX transfer relay) path

R1 K0 has its own path: loop 2 (FT-710 TX GND) - U2 opto - PTT_N - U5 inverter - TX_ANY - R51 0R - R1_K0_DRV - J14 - Q101 gate. R2 and R3 K0 are driven by U903 IO1_3 and IO1_4 after the TX handshake (D-63; R52, R53 not fitted). The K0 coils are on +12V_RLY, so RLY_EN does not switch them (D-27); RLY_EN low resets U903, so R2 and R3 K0 drop (F12). The table is for R1.

| PTT loop 2 | Controller on J14 | +3V3 on controller | RLY_EN | TX_ANY / K0 gate | K0 contacts | Radio sees |
|---|---|---|---|---|---|---|
| open | yes | ok | 1 | 0 | NC (RX) | RX row with row relays |
| open | yes | ok | 0 | 0 | NC (RX) | RX row, row relays off: open line |
| open | yes | off | 0 | 0 | NC (RX) | RX row, row relays off: open line |
| open | no | ok | Z to 0 | 0 | NC (RX) | RX row, row relays off: open line |
| closed | yes | ok | 1 | 1 | NO (TX) | TX row with row relays |
| closed | yes | ok | 0 | 1 | NO (TX) | TX row, row relays off: open line |
| closed | yes | off | 0 | 0 | NC (RX) | RX row, row relays off: open line |
| closed | no | ok | Z to 0 | 0 | NC (RX) | RX row, row relays off: open line |

**Finding F2 (design).** PTT with RLY_EN = 0 (KILL, fault, MCU not ready) still moves K0 to the TX row, but every row relay is open: the FT-710 then transmits into an open TX row. The radio sees a very high SWR. Gating the K0 drives with RLY_EN does not help: the radio would then transmit into the open RX row. Options for a later decision: (a) a TX inhibit line from the controller back to the radio (FT-710 input to check), or (b) accept and rely on the radio's own SWR protection.

**Finding F3 (firmware, revised for D-63).** U903 IO1_2 (R1 K0 read-back) and IO1_5 (TX_ANY read-back) share their nets with the U5 output: they must stay inputs. IO1_3 and IO1_4 drive R2 and R3 K0 (outputs), which is safe only while R52 and R53 are not fitted (checked above). Build rule: never fit R52 or R53 together with firmware that drives IO1_3 or IO1_4.

**Finding F4 (design, closed).** TX_ANY on the RF board had no pull resistor, so U903 IO1_5 floated with J14 open. R904 100k pull-down added (D-61); the topology check above confirms it.

Readings: S1 the relays wait for the explicit clear after power-up. S2 a hung main loop drops RLY_EN at the time-out (0.9 to 2.5 s after the last WDI edge) and it stays low, because every reset sets FAULT again. S4 a clear edge during reset does nothing. S5 a brown-out needs a new clear. S6 KILL acts at once and is not latched: RLY_EN returns when the loop closes. S3 and S7: a crashed MCU that keeps toggling LATCH_CLR, or that kicks WDI from an interrupt, defeats the gate.

**Finding F5 (firmware, reworded after D-62).** KILL is not latched in the box (S6); the SAFE latch is in the shack (D-75). RLY_EN = 0 holds the expanders in reset, so when KILL returns to 0 the relays come back off, and the expander registers are at their defaults. Rule: after KILL returns to 0, set up the expanders again (F1 order) before any switching. Do not set MCU_EN_N = 1 on KILL = 1: under D-62 that opens READY and keeps the SAFE loop open (F11, verify_system.py).

## 7. Crossbar: relay states on one antenna column

Per column c: six row relays (R1 TXc, R1 RXc, R2 TXc, R2 RXc, R3 TXc, R3 RXc) and K1c (on = column to the antenna, off = antenna parked on the bleed). Hazards, for all TX rows (conservative: every TX row can carry RF when its K0 is in TX): H1 two TX rows on one column; H2 a TX row and a row of another radio on one column (TX power into that radio); H3 a TX row on an RX-only column (A2, bias-T and preamp); H4 a TX row on a column with K1 off (open line).

| Column | Allowed states (of 128) | States with H1 | H2 | H3 | H4 |
|---|---|---|---|---|---|
| A1 | 22 | 64 | 100 | 0 | 56 |
| A2 (RX only, TX relays not fitted) | 16 | 64 | 100 | 112 | 56 |
| A3 | 22 | 64 | 100 | 0 | 56 |
| A4 | 22 | 64 | 100 | 0 | 56 |

Allowed states in words: a column either carries one radio with its TX row and/or RX row (TX only with K1 on), or it carries RX rows of several radios (shared receive antenna), with K1 on or off. On A2 no TX row at all: since D-103 the A2 TX relays are not fitted, so the H3 states cannot occur in hardware (SR-01).

Per radio, across the columns: at most one TX row relay and at most one RX row relay closed (two TX rows would put the transmitter on two antennas; two RX rows parallel two antennas). The EXP relays (TXE, RXE) count as a column of their own, used by that radio only.

**Finding F6 (firmware).** No hardware interlock covers H1, H2 and H4; H3 is excluded in hardware on A2 (D-103). The firmware must check every requested state against these rules before any relay moves, and keep a column table (TX or RX only) that matches the fitted relays. `is_state_allowed()` below is the reference implementation.

## 8. Switching sequence and timing (derived firmware rules)

RT1 (RT1pb rev 4): operate 8 ms max, release 6 ms max, bounce 4 ms (form A) / 6 ms (form B) max.

| Step | Action | Wait | Reason |
|---|---|---|---|
| 1 | Check TX_ANY = 0 (U903 IO1_5) and the new state with is_state_allowed() | - | no relay moves under RF (hot switching); H1 to H4 |
| 2 | Open the row relays that change | 6 + 6 = 12 ms | release plus NC bounce: break before make |
| 3 | Set K1 of every column that the new state uses | 8 + 4 = 12 ms | column terminated before a TX row closes (H4) |
| 4 | Close the new row relays | 8 + 4 = 12 ms | operate plus bounce before RF is allowed |
| 5 | Read back the output registers and TX_ANY | - | the state is what the firmware wrote |
| 6 | Open K1 of columns no longer used (parks the antenna on the bleed) | 12 ms |  |

**Finding F7 (station).** K0 follows PTT in hardware and needs 8 ms operate plus 4 ms bounce. The FT-710 must not send RF within 12 ms after PTT closes. Rule: set the radio TX delay to at least 15 ms (FT-710 menu item to check). A PTT during steps 2 to 4 is possible; the firmware cannot stop it (see F2).

**Order on a KILL.** The coil MOSFETs turn off after about 11.2 us, +12V_SW after about 18.6 us (estimate). If +12V_SW opened first, the current would circulate for a moment through the freewheel diode on +12V_SW (slow decay). The margin rests on two first-order estimates: measure it (scope on a gate, +12V_SW and one coil during a KILL).

## 10. Firmware rules from this verification

1. Kick WDI (falling edge) only from the main loop after its checks; interval 0.25 s or less (C-19). Never from a timer interrupt (S7).
2. Give a LATCH_CLR edge only once after the start-up self-test, and after a fault only when the cause is checked (S3).
3. Start-up (after D-62, F11): RESET_N high, MCU_EN_N = 1, LATCH_CLR edge, then MCU_EN_N = 0, then wait for KILL = 0 (SAFE loop closed) with a time-out, then write PCA9539 output registers 0x00, then configuration registers (F1), then check TX_ANY = 0.
4. Keep U903 IO1_2 to IO1_5 as inputs (F3).
5. On KILL = 1: the relays are off in hardware; after KILL = 0 and TX_ANY = 0, set up the expanders again (F1) and use a fresh switching sequence (F5, F11).
6. Check every requested relay state with is_state_allowed() (H1 to H4, one TX and one RX row per radio) (F6).
7. Switch only with TX_ANY = 0, in the sequence of section 8, with the 12 ms waits (RT1 timing).
8. Bias-T feed only on RX-only ports (A2), and only when no TX row is on that column (A-10). Fault = EN 1 and OK 0: switch the feed off and report (D-54).
9. Set every spare expander pin as an output driving 0 (F8).
10. Open and close relays in separate register writes, 12 ms apart (F10).
11. Station: radio TX delay at least 15 ms (F7); RF tail after PTT release shorter than the K0 release time, to measure (F9).

## 11. Reference implementation of the state check

```python
def is_state_allowed(tx, rx, k1, rx_only=frozenset({2})):
    """tx[r], rx[r]: column (1..4, 'E') or None per radio r; k1: set of columns with K1 on. True if no hazard H1 to H4."""
    for c in (1, 2, 3, 4):
        tx_r = [r for r in tx if tx[r] == c]
        any_r = {r for r in tx if tx[r] == c} | {r for r in rx if rx[r] == c}
        if len(tx_r) > 1: return False                             # H1
        if tx_r and any_r - {tx_r[0]}: return False                # H2
        if tx_r and c in rx_only: return False                     # H3
        if tx_r and c not in k1: return False                      # H4
    return True
```
